# 爽点与开篇钩子：可执行清单

> 这份文档解决的是“故事看不下去”，不是“句子不够漂亮”。
> 结论先说：文笔连贯只是及格线；读者继续读，是因为他心里有一个具体的“我想看他赢”，而且每章都能看到一点兑现。

## 1. 爽点到底是什么

不是主角一直赢，也不是每章都打脸。爽点是：

1. 读者先有一个具体的期待：想看主角赢什么、被谁认可、出哪口气、得到什么；
2. 一个具体的人或规则不公平地压住他；
3. 他用前文已经埋过的工具、信息或规则翻回来；
4. 结果被看见：谁被打脸、他得到什么、谁在场；
5. 本章先还一笔小债，再留一个更大的问题。

一句话：**先欠读者一口气，再当着他面还上。**

“情绪渲染”是让读者在乎；“爽点”是让读者觉得这口气出得值。两者不是一回事。只有情绪没有兑现，读起来像案卷；只有兑现没有情绪，读起来像游戏通关。

## 2. 这次 10 章为什么没有爽点

- 它是古风悬疑权谋，主角沈砚一直在查案、逃命、护人；每章结束都是“新问题”，但很少“他赢了什么”。
- 第 10 章他救出阿棠父女、送出粮册，但城主替身还在、裴照没倒、他还在被追。这是“活下来”，不是“翻盘”。
- 第 7 章老周旧伤、阿棠叫“爹”，第 8 章“我听见你摔了”，是很好的“刀”和情感兑现，但不是“爽点”。读者会难过，不会拍桌子。
- 管线层面也有原因：原 `ScenePlan` 有目标、阻碍、代价、情感，但没有“读者想看什么赢面”和“本章怎么兑现”；质量门的“钩子”维度又把“未解问题”当成钩子。所以 83 分只能说明“没有明显毛病”，不能说明“好看”。

## 3. 《没钱修什么仙》可学的机制

不学它的设定、句子和人物，学它“怎么让读者想往下看”。

- **一句话高概念**：修仙 + 网贷 + 教育内卷。读者一听就知道冲突从哪里来。
- **开头先给具体危机**：催款、天台、面试，不是先讲世界观。主角先被逼到墙角，读者才愿意看他怎么爬出来。
- **荒诞规则一本正经地执行**：越是用公文、合同、流程的口吻写荒唐事，越好笑；不是靠网络梗。
- **笑点下面有真痛**：穷、家庭、阶层、被规则卡住。无厘头是减压阀，不是全部；没有里子，笑完就忘。
- **爽点可以延迟，但方向要明确**：先让主角惨，再给外挂/翻盘的期待；读者知道“他迟早要赢”，只是不知道怎么写。
- **日常转化链**：现实痛点 → 制度/资本逻辑 → 修仙规则 → 日常场景 → 荒诞细节 → 情绪释放。

## 4. 知乎盐选可学的开头密度

- 第一句就要有问号、冲突或反常，不铺垫天气和历史。
- 前 300 字进冲突；3000 字内完成“人物 + 冲突 + 悬念”。
- 大约每 1000 字有一次情绪波动；每 2000–3000 字有一次小兑现。
- 情绪债分期还：先欠，再还一点，再欠更大的；不要一直欠。
- 细节要具体、反常、有画面；“人性深渊”这种抽象词不如“他袖口沾着半干的血”。
- 第一人称不是万能，但“近距离口述感”值得学；长篇可以用第三人称限知，把这种密度放在开头和每章兑现点。

## 5. 写之前先填“爽点卡”

| 字段 | 要回答的问题 |

| `reader_promise` | 读者这一章最想看到什么赢面？ |
| `suppression` | 谁或什么规则不公平地压住主角？ |
| `payoff_tool` | 主角用前文埋过的什么工具/信息/规则？ |
| `payoff` | 本章兑现了什么？谁被打脸/得到什么/谁看见？ |

| `debt_paid` | 本章先还哪笔情感债？ |
| `debt_opened` | 本章又欠下哪笔情感债？ |

### 填卡示例（修仙界 315）

- 开篇钩子：飞升大典上，九霄仙尊刚喝完飞升灵酒，就被雷劈成了焦炭。
- 读者赢面：想看一个没修为的小检测员当众拆穿丹王。
- 压制：丹王是金丹期大修士，官方已经定调雷劫失败，保安把许青往外拖。
- 兑现工具：315 封条、检测玉简、胖三的留影玉镜。
- 兑现：许青当众读出配料表，把封条贴在丹王旗舰店门上，丹王被迫认赔。
- 谁看见：围观修士把留影玉镜举高，跟着喊假一赔十。
- 更大的问题：丹王背后是雷部；检测玉简被捏碎。
- 先还的小债：九霄仙尊的死因初步查清。
- 新欠的债：许青答应给死者家属一个交代。

## 6. 每章自检

写完一章，按顺序问：

1. 前 3 段有没有具体反常/利害/承诺？还是天气、历史、日常？
2. 读者能不能用一句话说出“这章我想看他赢什么”？
3. 压制是不是具体、不公平、有名有姓？还是“气氛很压抑”？
4. 兑现用的工具/信息，本章前段或前文有没有出现过？是不是天降？
5. 兑现的结果能不能被看见？谁被打脸、主角得到什么、谁在场？
6. 本章有没有先还一笔小债？还是只留了新问题？
7. 章末的新问题，是不是比本章的兑现更大？还是把本章的兑现吞掉了？
8. 如果删掉所有打斗/气氛描写，本章还剩不剩一个“赢/输/得到/失去”的结果？

## 7. 常见误区

- **把“留悬念”当“爽点”**：悬念是欠债，爽点是还债。每章都欠，读者会累。
- **把“主角很惨”当“爽点”**：惨是压制，不是兑现。惨完必须让他用前面的准备翻一次。
- **把“众人震惊”当“打脸”**：打脸要有具体结果：赔钱、封店、停职、认错、失去资格、被带走。
- **天降外挂**：兑现的工具必须是前文埋过的；读者要能回想“原来那一笔在这儿等着”。
- **一直赢**：没有压制就没有爽点；主角可以输，但输要有代价、有信息、有下一步。
- **网络梗堆砌**：梗会过期；规则与现实的错位不会。人物要一本正经地做荒唐事。
- **只学开头**：盐选的开头密度可以学，但长篇不能每章都像短篇开头；每章要有自己的小兑现。

## 8. 自动化的边界

质量分能抓“碎、冗余、情绪直给、总结式收尾”，抓不到“好不好看”。爽点目前靠 `ScenePlan` 的爽点卡 + 生成契约 + 人工试读；后续可以加一个独立的“爽点审查”LLM 规则，但不能用现有 83 分代替人读。

### 10.3 旧小样为什么生硬

1. 第一段是舞台说明，不是人的视角：先写大典、流水席、金签小字，再写仙尊被雷劈；读者还没认识任何一个人，先看了一场段子。
2. 丹王那句“雷劫失败，正常现象，大家继续吃席”是段子，不是人的反应。一个金丹丹王在三百桌宾客面前死了人，第一反应不该是讲冷笑话，而是压场、推责、找替罪羊。
3. 许青三次走回旗舰店，没人拦、没人抓、没人怕；反派的权力只存在于台词里。零修为临时工当众贴封条，金丹丹王只赔一颗下品灵石，这不是荒诞，是算术和权力关系都不对。
4. 每句都在解释笑点：“说人话就是”“准得跟瞄了八百年似的”“筑基是筑面筋吧”。读者被反复提醒“这里该笑了”，反而笑不出来。
5. 主角没有私心、恐惧、代价；他只是在替作者完成“315 打假”的流程。读者不会替一个流程工具人紧张。
6. 每章都“查案—曝光—打脸”，没有人物关系，也没有真正的损失；爽点来得太容易，等于没有爽点。
