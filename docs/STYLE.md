# 镜头感、简洁、连贯与情感节拍文风卡 v0.5

> 目标：让读者读文字时，脑子里能自动“放电影”，并且**先被事件抓住，再被情感击中**。
> v0.5 修正 v0.4 的一个偏差：把“一句一动作”当成所有段落的默认写法，导致句子太短、对话太多、场景之间没有桥，读起来碎。v0.5 保留动作戏的简洁，补回叙述的连贯、人物的声口和关键物件的回指。
> 这里拆的是“镜头调度、句子经济、场景承接、人物声音、情感蓄力”这一层，不复制任何作家的句子，也不要求模仿某一种文风。参考样本与拆解见 [STYLE-STUDY.md](STYLE-STUDY.md)。

## 1. 先判断：这段描写有没有任务

每一段描写至少完成一项：

- 交代空间：读者知道谁在哪、离多远、中间隔着什么；
- 推进动作：局势发生了变化；
- 暴露人物：读者看出他想要什么、怕什么、在隐瞒什么；
- 埋线索：后面的反转有依据；
- 制造压力：读者感到时间、危险或代价。

一项都不占，就是装饰，删掉。

## 2. 简洁：动作峰值一句一拍，叙述段落要连

这是 v0.4 最容易犯的错：把“一句只做一个主要动作”当成所有段落的默认写法，结果动作戏清楚了，叙述却被切成动作提示，读起来碎。

先分两种段落：

- **动作峰值 / 紧张瞬间**：一句一个主要动作 + 一个必要结果；短句、短段，让读者跟上空间和胜负。
- **叙述 / 过渡 / 推理 / 情感 / 关系**：允许复合句，允许 2-5 句成段，允许 40-150 字；因果、时间、空间、人物判断要写出来。这些不是装饰，是读者不迷路的桥。

三条规则：

1. **动作峰值一句一拍；叙述段落要连。** 不要把所有段落都写成 4-8 字。该长的地方长，该短的地方短，节奏才有呼吸。
2. **不为“具体”追加不影响局势的细节。** 例如水珠、衣角、灰尘，如果它不参与后面的动作、人物或线索，就删。
3. **短句是节奏，不是碎句。** 同一拍里的三个短句能合并就合并；不同拍的动作不要硬塞进一句。删填充词：整个人、一下子、猛地、只觉、顿时、只见、原来、其实、像是（除非提供新信息）。

**判断标准**：读完这一段，读者能不能自己说出“谁在哪、刚才发生了什么、现在最要紧的是什么”？如果必须靠猜，那不是简洁，是断线。

对照：

- 动作峰值原句：`刀锋擦过左肩，衣料裂了，皮肉没破。`
- 改：`刀锋划破左肩衣料，未及皮肉。`

- 动作峰值原句：`第二道影子贴到背后，一肘撞在腰侧，他整个人撞上槐树，震落一串水珠。`
- 改：`第二道影子贴到背后，一肘撞在腰侧，他整个人撞上槐树。`

第二句删掉“震落一串水珠”后，动作、伤势、局势都没有损失，所以它是装饰。

- 叙述段落原稿（碎）：
  > 沈砚伏在墙头。追兵没上墙。他跳下墙。阿棠在捡药包。她的手在抖。
- 改（连）：
  > 沈砚伏在墙头，看见追兵没有上墙，反而朝药铺后门收过去。他本可以沿着墙头往北，巡夜司就在两条街外；可门缝里那只手抖得连药篓都拖不住。他跳下墙，进了巷子。

改后没有多写形容词，只补了“他看见什么、他本来可以怎样、他为什么改变主意”。这就是叙述段要承担的承接。

## 2.5 连贯：段落是场景的单位

碎感的根源通常不是“句子短”，而是“场景没有脊柱、段落没有承接”。

1. **每场戏先回答五个问题**：谁想要什么？什么阻止他？他做了什么选择？代价是什么？这场戏结束时局势变成什么样？答不上来，先别写。
2. **每个段落承担一个节拍**：一个判断、一个动作、一个信息变化、一个关系变化。不要把同一拍的“看—想—做”拆成三个互不相干的短段。
3. **段落之间要有桥**：时间桥（“雨停之前”）、空间桥（“从后巷绕到东街”）、因果桥（“因为裴照那句话，他改了路”）、人物桥（“阿棠还在等他解释”）。桥不是套话，是读者需要的方向。
4. **连续短段只用于三种情况**：动作峰值、喜剧节拍、刻意的强调。超过三四个，就要回到一个能承接的叙述段。
5. **每三到五段要有一次变化**：局势、信息、关系、目标，至少变一个。没有变化，读者就会觉得“读了后面忘了前面”，因为前面没有留下钩子。
6. **场景切换不要只靠空行**。空行是排版，不是叙事；至少用一句话交代“谁在什么时间、为什么到了这里”，或者让上一场的一个问题跟过来。

## 3. 镜头：选择拍什么

1. **开场两句内给一个可见锚点**：光、物件、声音、天气。锚点要和人物当前目标发生关系，不做纯风景展示。
2. **静态环境不超过两句**：只写视角人物此刻会注意到的；不写“全景旅游”。但如果环境本身是人物当下的困难（饥饿、寒冷、追兵、堵车），可以多写两句，因为它参与行动。
3. **动作写“意图—距离—结果—代价”**：一次交锋最多三拍；不写全套招式，不用“刀光剑影”“金铁交鸣”这类空泛套话。
4. **紧张处用短句、短段**：每三到五段要有一次局势、信息或关系变化；段落长短跟着人物的呼吸走。
5. **不写情绪标签**：不写“他很愤怒/伤心/震惊”；写手、呼吸、物件、动作、别人的反应。
6. **章末落在画面、动作或未解问题上**：不落在总结、道理、情绪抒情上。

### 视角纪律

- 只写视角人物能看到、听到、闻到、摸到、想到的。
- 别人的心理只能通过表情、动作、语气推断；不写“他心里想”。
- 不解释读者能自己推断的事。留白不是省字，是把推断的乐趣留给读者。

### 动作戏的镜头顺序

1. **空间**：谁在哪，障碍物是什么，光/声音如何。
2. **意图**：谁先动，为什么现在动。
3. **交锋**：只写关键一拍，写距离、落点、结果。
4. **代价**：谁受伤、失去什么、局势怎么变。
5. **收束**：一个画面或声音，不总结。

### 3.5 留白：情感节点少写一步

这是 v0.2 还没解决、试读时被指出的问题：**动作戏写得清楚，情感戏也写得太清楚**。人物先走到哪、抓不抓袖子、药瓶怎么塞、说完什么表情，全都交代完，读者只剩“收到”，没有推断空间。

规则：

1. **动作戏要清楚，情感戏要含蓄。** 打斗必须让读者知道谁在哪、刀从哪来、结果如何；情感/关系/余韵节点，不需要把走位、手势、眼神、意图全部写满。
2. **情感节点只留一个动作或一句台词。** 不要同时写“走过来 + 抓住袖子 + 塞药瓶 + 说台词 + 心理活动”。读者能从台词推断的距离，不写；能从动作推断的态度，不解释。
3. **“少写一步”不是“让人看不懂”。** 谁在说话、东西有没有递出去、局势有没有变化，仍要清楚；省掉的是读者自己能补的那一步。
4. **越重的情感，越要克制。** 大爆发之后不要立刻解释人物为什么爆发；留一个动作、一个物件、一句不相干的话，让余震自己扩散。

对照（本轮第 2 章样章，用户改稿）：

- 原：
  > 阿棠从神龛后出来，走到他面前，抓住他袖子。
  >
  > “你为什么回来？”
  >
  > 沈砚把金疮药瓶塞进她手里。
  >
  > “先换药。”
- 改：
  > 阿棠从神龛后走出，“你为什么回来？”沈砚递上金疮药瓶。“先换药。”

删掉的内容：

- “走到他面前”：台词一出口，读者自然知道她靠近了；
- “抓住他袖子”：关系推到“抓袖子”就太实，反而替读者做了判断；
- “把……塞进她手里”改成“递上”：力度轻了，态度变得不明——是关心、是回避、还是习惯？读者自己判断。

保留的内容：

- 她问“你为什么回来”——这是本章情感债的兑现点；
- 他递药、说“先换药”——用动作和台词回答，不解释。

**注意**：这段能留白，是因为前面已经写了她受伤、他不肯走。如果前面没有蓄力，只写“递药”就会变成信息不足，不是留白。

### 3.6 缺席也是镜头：用“谁不在场”制造问题

有时最重的情绪不在场的人身上，而在“他为什么不在”。

《黎小鸭的人生路》里，外公没有参加公开葬礼。读者第一反应可能是“他还在恨”；后面才交代，他不去是因为早年涉黑、身份敏感，怕自己的出现把流言和追查引到外孙女身上。**缺席不是冷漠，是保护；但作者没有让旁白提前解释，而是先让缺席成立。**

节奏是：

1. 该出现的人没出现；
2. 读者产生问题：他到底在不在乎？
3. 给一个只属于他的私密场合；
4. 让他做一件公开场合不会做的事；
5. 不解释，留一个动作、一句话或一个空镜。

规则：

- 重要人物在该出现的场合缺席，可以是一个问题；不要用旁白替他解释“其实他很爱她”，先让缺席成立。
- 私下到场比公开演讲更有力。公开场合人物会表演，私密场合才可能说真话。
- 缺席不能滥用。它只适合主债级别的情绪；每章都玩“他其实没来”，读者会疲劳。

### 3.7 人物声音：不是所有人都短促寡言

v0.4 的样章里，沈砚、老周、阿棠、裴照都短、都克制、都用句号收尾。遮住名字，读者很难分辨谁在说。这不是“人物性格高冷”，是**叙述声音没有区分**。

人物声音不是给每人一句口头禅，而是六个变量：

| 变量 | 要问的问题 | 例子 |
|---|---|---|
| 句长 | 他习惯长句还是短句？ | 老臣用长句绕，武将用短句砸 |
| 词汇 | 他用什么行当的词？ | 仵作用“尸斑/切口”，商人用“本钱/折耗” |
| 称呼 | 他怎么叫对方？ | “大人/你/小子/沈公子”立刻分出关系 |
| 直接程度 | 他问不问、说不说、绕不绕？ | 有人直问，有人只说半句 |
| 关注点 | 他先看什么？ | 捕头看手，医女看伤，商人看账 |
| 撒谎方式 | 他回避时做什么？ | 有人反问，有人沉默，有人突然热情 |

写法：

1. **先给每个主要人物写一行“声口卡”**：句长、词汇、称呼、直接程度、关注点、撒谎方式。不要写“性格高冷”这种形容词，要写可执行的说话习惯。
2. **同一场戏里，让两个人用不同方式回答同一个问题**。例如“你昨晚去哪了？”——一个人报时间地点，一个人反问“你听谁说的”，一个人先沉默再递东西。
3. **叙述也可以带视角人物的声口**。限知第三人称不是中性摄像机；沈砚看到的、想到的、计较的，可以带他的职业习惯和偏见。
4. **不要为了“个性”让人物说怪话**。声口来自职业、出身、处境和目的，不是口头禅堆砌。

对照（同一句意思，三种人）：

- 老捕头：`“后巷那摊水，今早还没干。你鞋底倒是干净。”`
- 年轻仵作：`“你鞋底的泥是后巷的，颗粒粗，混着药渣。你去过药铺。”`
- 圆滑幕僚：`“沈公子辛苦。这么晚还在外头走，是替巡夜司办事，还是替自己办事？”`

三个人都在试探，但句长、词汇、直接程度不同。读者不用看名字，也能大致分出谁在说话。

### 3.8 回指：让读者记得前面

“读了后面忘了前面”不一定是读者记性差，很多时候是作者没有回指。回指不是复述，是在新的场景里自然提起旧物件、旧问题、旧债。

1. **关键物件每次出场要带一点新信息**。半张图第一次是“图”，第二次是“硌着胸口的硬角”，第三次是“裴照每问一句，那个角就往下压一分”。同一个物件，每次出现都推进压力。
2. **关键问题要在场景开头或转折处被重新提起**。不用长篇解释，一句就够：“老周说的初七，还有三天。”
3. **情感债要有人记得**。谁欠谁什么，不能只在账本里；至少让欠债的人做一个动作、让讨债的人看一眼、让旁观者提一句。
4. **章末的钩子要能接上章首**。上一章结尾的问题，下一章开头不要立刻丢；先让角色带着它走一段，再给新事件。
5. **不要用“前情提要”式复述**。回指要长在场景里，不是作者跳出来总结。

## 4. 情感：先蓄力，再爆发

事件是骨架，情感是电流。只有“发生了什么事”，读者会看完就走；只有“这件事对他意味着什么”，读者才会追下一章。

### 4.1 单章情感曲线

不要一上来就爆发。一个可用的顺序：

1. **基线**：人物平时怎么说话、怎么处理事。读者先知道他“正常”是什么样。
2. **小刺**：一个小的不顺、误解、回避、损失。读者开始替他憋一口气。
3. **压抑/误判**：人物用旧办法处理，但没用；或者他误会了对方。
4. **逼近**：代价变具体——再退一步就会失去什么。
5. **爆发/释放**：人物做出一个之前不会做的选择。用动作、台词、反转或物件兑现，不用解释。
6. **余震**：爆发后不要马上总结。留一个动作、沉默、画面或未解问题。

### 4.2 蓄力靠什么

- **具体想要**：不是“他想查案”，而是“他今天必须从老周嘴里拿到换防时间”。
- **具体阻碍**：不是“有人阻止”，而是“老周每次提到钥匙就转开话题”。
- **具体代价**：不是“很危险”，而是“问多了，老周会被裴照灭口”。
- **具体选择**：人物在“要答案”和“保人”之间选一个，读者才知道他在乎什么。

### 4.3 爆发不要靠形容词

- 不写“他怒不可遏”，写他做了一件平时不会做的事：把茶杯捏裂、笑了一下、把刀收回鞘、转身走。
- 不写“她很感动”，写她把药瓶握紧、低头、说了一句不相干的话。
- 不写“全场震惊”，写一个具体的人掉了筷子、退了半步、改了称呼。

### 4.4 跨章情感债

和伏笔一样，情感也需要“记账”：

- 谁欠谁一个道歉、一个解释、一次选择、一次兑现；
- 读者先被欠了什么，后面在哪一章还；
- 还的时候不能靠新设定，要靠前面已经埋好的关系和行为。

跨章情感债现在有独立账本 `emotional_threads`：登记“谁欠谁、欠什么、第几章欠下、计划第几章还、重要度、状态”。主债 `importance=5`，小债用更低重要度。生成时账本会进入 L1；`target_payoff_chapter` 到期只产生 minor 提醒（R07），不强制回收——可以故意拖，拖到读者以为没戏了再还。账本目前由规划层/人工登记，小说正文不会自动改它。

### 4.5 事件情绪爆发：先欠，再还，最后只给一句话

以《黎小鸭的人生路》的“外公坟前同意”为例（只引一句短台词，不复制正文）：

1. **前置蓄能**：小鸭在外婆房间翻到旧信、照片、信物，知道母亲和惜年相爱，也知道外公当年强烈反对。更重要的是，她发现外公的反对不完全是嫌贫爱富：他早年涉黑，怕自己的身份拖累女儿和惜年。读者对他的判断从“刻薄长辈”变成“有苦衷但确实做错的人”。
2. **第一次小释放**：亲缘鉴定确认，章老先生说“可以叫我爷爷了”。这是爷孙相认的情绪释放，但**主债没有还**：外公对那段婚姻的“不同意”还悬着。读者刚松一口气，又被留下一个问题。
3. **第二次蓄力**：葬礼。两个骨灰盒并排，补一场迟到的婚礼；外公却没有出席。读者不知道他是冷漠、是不敢来、还是另有原因。缺席把问题吊起来。
4. **高潮**：宾客散尽，外公独自来到墓前，说：“我同意你们结婚了。”没有解释，没有道歉长文，没有旁白总结。

为什么这句能炸：

- 还的是**几十年前欠下的“同意”**，不是新信息；
- 在坟前说“同意结婚”，对象已经死了，婚礼不可能补办，**迟到的代价自己说话**；
- 没有观众，他不是在演给活人看；
- 只有一句台词，前面所有铺垫由结构承担，读者自己把情绪补完。

写的时候要避免：

- 不要写“情绪冲到顶点”“轰然崩塌”“所有人泪目”——这是作者替读者下结论；
- 不要让外公在公开葬礼上演讲；公开场合他会表演，私密场合才可能说真话；
- 不要在台词后马上解释“这句话意味着什么”；留风、墓碑、背影、香灰。

管线里怎么拆：

- 一条情感债 = **谁欠谁 + 欠什么 + 什么时候还 + 还的时候谁在场/谁缺席**；
- 认亲章：`debt_paid` 写“小鸭确认身世”，`debt_opened` 写“外公仍未同意那门婚事”；
- 葬礼章：`debt_opened` 写“外公缺席，读者不知道他会不会来”，不要在这一章把主债还掉；
- 坟前章：`debt_paid` 写“外公的‘同意’”，`aftertaste` 只写一个画面，不写解释。

主债只有一个：**谁最需要谁的承认/选择**。其他是小债（认亲、解释、道歉、救一次）。小债可以早还，让读者喘口气；主债必须留到能改变人物关系的那一场。认亲章如果把“外公同意婚事”也一起还了，后面的坟前戏就没有债可还。

### 4.6 叙述声音：限知不等于摄像机

v0.4 的“只写视角人物能看到、听到、闻到、摸到、想到的”是对的，但样章把“想到的”也删了，只剩镜头。结果读者知道发生了什么，却不知道这件事对人物意味着什么。

限知第三人称可以写：

- 他的判断：`这不对。老周擦柜台的手太稳了。`
- 他的算计：`再问一句，老周就会翻脸；不问，今晚白来。`
- 他的回忆：`上一次见这种铜印，是在父亲的旧箱底。`
- 他的自嘲/偏见：`巡夜司的规矩，永远在该死的人死后才到。`

不能写：

- 别人的心理：`老周心里其实很害怕。`（只能写老周的手、眼、语气）
- 全知总结：`这一刻，两个人都明白，事情再也回不去了。`
- 作者解释：`沈砚之所以回来，是因为他良心不安。`

**判断标准**：把这段内心声音删掉，读者还能不能理解人物的选择？能理解，可能是解释；不能理解，说明它是必要的蓄力。

## 5. 幽默、反转、爽点、刀

这些不是“调料”，是情感曲线的不同形状。

- **幽默**：先让读者按一个预期走，再让人物用他自己的方式拐弯。幽默来自人物性格和处境，不靠段子堆砌。
- **反转**：先给一个合理预期，再用**前面已经埋过**的信息翻面；不能靠临时新设定硬转。
- **爽点**：压制 → 蓄力 → 反击 → 兑现。兑现要具体：对方改口、局势翻盘、旁观者反应，不要用旁白夸“太厉害了”。
- **刀**：先让读者喜欢、在乎，再拿走；不是硬虐。刀点之后留余震，不要立刻用解释冲淡。
- **感动**：克制。人物做一件小事，读者自己得出结论；作者不要替读者哭。
- **姨母笑/甜**：关系推进靠小动作、偏爱、误会、欲言又止；不要用旁白说“好甜”。

> 爽点是独立于“情绪渲染”的一层：读者要先有一个具体的“我想看他赢”，再用前文埋过的工具/规则兑现；只有情绪没有兑现，读起来像案卷。完整的“爽点卡”、开篇钩子和每章自检见 [PAYOFF.md](PAYOFF.md)。

### 5.5 题材语域：同一套规则，不同的默认节奏

| 题材 | 默认句长/段落 | 描写重心 | 对话特征 | 要避免 |
|---|---|---|---|---|
| 古风悬疑/权谋 | 中长句为主，动作峰值短 | 器物、礼数、座次、光线、气味 | 称呼、暗示、留半句 | 现代梗、解释性旁白、所有人短句 |
| 都市重生/轻喜剧 | 长句内心 + 短句对话 | 钱、房、工作、身体、生活细节 | 口语、反讽、抢话、段末反转 | 只有短对话没有内心账本 |
| 仙侠/玄幻 | 中长句写意象，短句写交锋 | 身体感受、尺度、天象、代价 | 师门称呼、规矩、克制或张狂 | 空泛的“恐怖如斯”、设定倾倒 |
| 历史/职场 | 长句因果链，短句落锤 | 制度、数字、文书、流程 | 官腔、敬语、潜台词 | 现代管理词、作者炫学 |
| 科幻/悬疑 | 短句写紧张，中句写原理 | 设备、数据、空间、异常 | 术语、命令、冷静的黑色幽默 | 讲座式解释、全知视角 |
| 言情/情感 | 中长句写心理，短句写试探 | 小动作、距离、物件、沉默 | 欲言又止、反问、称呼变化 | 旁白说“好甜”、外貌堆砌 |

语域不是死模板。同一本书可以混用，但**一章之内要有主调**；主调由题材、视角人物和场景任务决定。

## 6. 场景卡：写之前先回答

生成前给每一章填一张卡（可以不填，模型会被要求在心里回答）：

- 前 3 段的具体反常/利害/承诺是什么？
- 读者这一章最想看到什么赢面？
- 谁或什么规则不公平地压住主角？
- 主角用前文埋过的什么工具/信息/规则兑现？
- 本章兑现了什么：谁被打脸、主角得到什么、谁看见？
- 兑现后更大的问题是什么？
- 视角人物此刻想要什么？
- 什么阻止他？
- 失败或拒绝的代价是什么？
- 读者应该先感到什么，再感到什么？
- 情感从哪里蓄力？
- 转折/选择是什么？
- 怎么释放？
- 章末留什么余韵？
- 本章兑现前面欠下的哪条情感债？
- 本章又新欠下什么情感债，准备在哪一章还？
- 爆发时谁在场、谁缺席？公开还是私密？

场景卡不是大纲的替代品：大纲说“发生什么”，场景卡说“这件事对谁意味着什么、读者为什么想看他赢”。前六问是“爽点卡”，中间是场景脊柱，最后三问是单章内的“情感钩子”；跨章账本由 `emotional_threads` 承担。场景卡写“本章还/欠哪笔债”，账本记录这笔债在全书里的状态；两者不会自动同步，定稿后需要人工或规划层更新账本。

## 7. 自检

- 删掉这段环境，剧情、人物或线索受影响吗？不受影响就是装饰。
- 删掉这个动作/细节，读者还能看懂谁占上风吗？能看懂就是多余。
- 这句里有没有两个小句在说同一件事？能合并就合并。
- 这段是在“演”还是在“讲”？“讲”的部分能不能改成动作、对话或物件？
- 这一章人物想要什么？如果答不上来，读者也不会在乎。
- 情感爆发之前，读者有没有被欠一口气？如果没有，爆发就是空的。
- 这句是在写关系，还是在写走位？如果是关系，删掉“走到他面前”“抓住袖子”这类走位，试试还成不成立。
- 这个情感节点，读者需要知道的是“谁做了什么”，还是“他为什么这么做”？后者不要写满。
- 这一章还的是小债还是主债？主债有没有被提前还完？
- 这场爆发有没有观众？如果有，人物是在说真话，还是在表演？
- **把对话全部遮住，剩下的叙述能不能撑起场景？** 如果只剩动作提示，说明叙述段太薄。
- **每个主要人物说话，遮住名字能认出是谁吗？** 如果都像同一个人，先改声口，不要加形容词。
- **上一段发生了什么，读者能不能用一句话说出来？** 说不出来，缺的是承接，不是篇幅。
- **这一段的因果桥在哪里？** 如果只能靠空行和读者猜，补一句“因为/所以/可是/于是”。
- **这一章有没有回指前面的关键物件/问题？** 至少让它在开头、转折、结尾各出现一次。
- **这句话是主角的判断，还是作者的总结？** 主角的判断可以留，作者的总结删掉。

## 8. 原创对照示例

以下用本项目人物，不引用任何现成小说。

### 示例 A：动作流水账 → 镜头 + 简洁

原稿（本轮生成）：

> 沈砚往前扑了半步，短刀出鞘，反手往上一格。金铁撞在一起，震得虎口发麻。黑衣人没出声，第二刀直取他胸口，像是知道那里揣着东西。

改后：

> 第一刀砍后颈。沈砚前跨半步，刀锋划破左肩衣料，未及皮肉。他反手拔刀横切，逼退左边的人；第二道影子贴到背后，一肘撞在腰侧，他整个人撞上槐树。

改后没有多写形容词，只保留空间（左肩、背后、槐树）、结果（衣料破、未伤肉、被撞实）和节奏。

### 示例 B：环境堆砌 → 选择性细节

原稿：

> 雨从檐角斜下来，砸在青石板上，溅起一层薄白。沈砚把油布包往怀里按了按，半张城防图的硬边抵着肋骨，隔着一层湿透的短褐，仍能觉出那道弯月形压痕的轮廓。

改后：

> 雨把青石板洗得发亮。沈砚贴着旧书库后墙走，怀里那半张图硌着肋骨。巷子只容一人，他侧身绕过一只倒扣的竹筐。

只保留三个会参与后面动作的细节：湿滑的地面、硌人的图、挡路的竹筐。

### 示例 C：情绪直给 → 动作与余震

原稿：

> 沈砚非常愤怒，但他知道自己不能发作，只能强忍着。

改后：

> 沈砚把刀按回鞘里，按了两次才扣上。他笑了一下，说：“行，我等着。”

不写“愤怒”，让读者从“按了两次”“笑了一下”自己得出结论。

## 9. 管线里怎么用

- `ContextAssembler._system` 默认注入“叙事镜头、连贯与人物声音要求”：动作峰值一句一拍，叙述段落要连；每场戏有“想要—阻碍—选择—代价—出口”；每章至少一次读者兑现；开篇前 3 段给具体反常/利害/承诺；主要人物有不同声口；关键物件要回指。
- `ContextAssembler._scene` 渲染可选场景卡；`GenerationRequest.scene_plan` 传入。场景卡新增 `opening_hook` / `reader_promise` / `suppression` / `payoff_tool` / `payoff` / `payoff_type` / `bystander_reaction` / `next_hook` 八个爽点字段。
- `_contract` 要求“按场景卡写”“每场戏至少有一次变化”“本章必须有一次读者兑现”“章末用画面/动作/未解问题收束”。
- `LLMChapterReviser` 的修订顺序改为“先补承接（场景脊柱、因果桥、人物声口、回指），再删装饰”；不要把“把所有句子改短”当成解决冗余的办法，也不要把所有对话拆成单句段。
- `LLMVerifier` 的 Q09“冗余/解释性重复”和 Q10“过度明确/留白不足”仍是 major，进入 polish；但 Q09 明确不把“必要的因果/过渡”误判为冗余，Q10 明确只删解释、不删承接和动作锚点。
- Q10 只用于情感、关系、余韵节点；打斗空间不适用，避免把“谁在哪、刀从哪来”删到读者看不懂。
- 如果一章的平均句长明显低于同题材参考值，或对话段占比很高但对话字数占比很低，优先检查“叙述段是否被切成动作提示”，而不是继续加形容词。
- 场景卡新增 `debt_paid` / `debt_opened` / `witnesses`，分别记录“还哪笔债、欠哪笔债、谁在场/谁缺席”。
- `emotional_threads` 进入 L1 选取：到期 → 主债（`importance=5`）→ 最近推进 → 最新，最多 8 条；L0 只显示未还计数。到期由 R07 报 minor，只提醒，不阻止定稿。

这些改动中，`emotional_threads` 和 R07 会进入记忆与一致性报告；但它们仍不改变“质量 accept 才能定稿”的主条件，R07 minor 也不会转人工。

## 10. 这张卡不能做什么

- 它不能自动判断“好不好看”。它只能把“动作流水账、环境堆砌、情绪直给、解释性重复、碎片化、人物声口趋同”变成更具体的写作指令。
- 爽点卡能逼模型先想“读者想看什么赢面”，但质量门仍没有一条稳定规则判断“爽点是否真的兑现”。当前靠 `rules+score` 加人工试读；不要把高分当成“好看”。
- 它不保证模型每次都遵守。需要真实章节试读；Q09 只能抓一部分冗余，Q10 只能抓“情感节点写得太满”，两者都不能抓“情感是否真的动人”，也不能判断“这笔情感债该不该现在还”。
- Q10 可能误伤：如果删掉一个动作后读者会看不懂空间或因果，那就不是留白不足，而是必要信息。判断标准是“删掉后场景是否仍成立”，不是“越短越好”。
- 现在的质量门还没有一条规则能稳定判断“碎”和“人物声音趋同”；Q01 只看单句段比例，Q05 只看句长分布，都可能漏掉“每段两句、每句很短、对话没有锚点”的写法。这类问题需要人工试读，或者后续加一条窄口径的“承接/声口”检查。
- 10 章回归证明方向，不证明每章都达标：ch06 超长、ch07 段落过密、ch08 因账本阻塞多次修订；账本边界已由 T4-0f 修复，长度和中文标点已由 T4-0g 加 Q12/Q11 告警，但都不替代人工修订。
- 它不是古龙模仿器。可学的是“选择拍什么、什么时候停”，不是某几句台词或某种句式。
- 跨章情感债已有 `emotional_threads` 表，但仍只支持规划层/人工登记；抽取器不会自动判断“这句话还了哪笔债”，也不会自动把账本改成 `paid`。R07 只能提醒到期，不能判断“这笔债现在该不该还”“还得好不好”。
